# Labour Hisab — Android Style Final

This version keeps the existing Labour Hisab functionality and data logic while applying the Android-style visual design shown in the reference mockup.

Highlights:
- Android-like blue header and bottom navigation
- Compact Add Project / Income / Expense buttons
- Same-size dashboard numbers (not enlarged)
- Small edit icon on projects, payments, cashbook and future plans
- Colorful Attendance controls: P / HF / A / OT
- Responsive mobile cards and rounded list items
- Dark mode, PWA manifest and offline service worker
- Existing LocalStorage-based data logic preserved

Deploy the folder on an HTTPS static host such as Netlify or Cloudflare Pages. Then install it from Android Chrome.
