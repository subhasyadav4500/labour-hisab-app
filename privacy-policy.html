Labour Hisab — Privacy Policy

Last updated: August 2026

What we store

This offline version stores the profile, workers, attendance, payment, project and cashbook records in the browser/device storage used by the app.

Where your data goes

This version does not send your labour records to a remote server and does not require an internet connection for core features.

Photos

Worker photos selected in the app are stored locally as compressed images in the device/browser storage.

Backups

You can export a JSON backup. Keep the backup file private because it may contain business and worker information.

Deletion

The app does not automatically delete your records. Clearing browser/app storage or using Reset App Data will remove local records, so make a backup first.

Future cloud sync

A future cloud-sync version would require a secure backend, authentication and a separate data policy. This offline build does not claim to provide multi-device cloud login.
